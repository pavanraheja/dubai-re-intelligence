How it works

  • The planner picks a tool; it never produces a number. Seven pandas functions compute everything. A model can be swapped in as planner and cannot override a refusal.
  • Refusals are rules, written down. Forward-looking, causal, advice, out-of-scope, supply and unknown-area questions are refused before anything is computed. Thin samples (<30 rows) get no answer at all.
  • Measured, not asserted. A labelled question set scores every change.
  • Known limits: current calendar year only (the public API serves no earlier data), so year-on-year is not computed; the registry records townhouses as villas; Emaar South is defined by project name, and every excluded project is listed in the extract report.
